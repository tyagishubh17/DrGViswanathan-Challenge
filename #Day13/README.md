# Day 13 - [Word Capitalization](https://codeforces.com/problemset/problem/281/A)

## Problem Description

Given a word, capitalize its first letter while keeping all other letters unchanged.

## Example

**Input:**
```text
ApPle
```

**Output:**
```text
ApPle
```

## Approach

Read the word as a string and convert its first character to uppercase. Then append the remaining characters as they are and print the resulting word.
